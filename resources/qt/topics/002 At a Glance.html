__TITLE__

This program is designed for maintaining bilingual dictionaries and learning foreign vocabulary. It is not language-specific and works for any language pair.

You can keep several dictionaries at once: create your own, share them, and import dictionaries made by others.

1. Dictionary

A dictionary is a collection of entries, each devoted to a single word. To create an entry, you only need to provide the word and at least one translation. Optionally, you can add multiple spelling variants and translations, word forms, phrases and usage examples, notes, and an illustration. Entries can be tagged, and favorite entries can be marked with a star.

1.1. Tags

Tags make searching easier and let you study specific groups of words.

1.2. Grammatical categories

Grammatical categories allow you to define word forms. For example, the category “Number” with the values “singular” and “plural” lets you record the forms: apple (singular), apples (plural).

The set of categories is not fixed, so you can add your own. This makes the program suitable for any language.

1.3. Escape sequences

They let you type characters that are not available in your current keyboard layout without switching it.

2. Practice

Practice mode includes various exercises: words, word forms, phrases, and so on. In each of them, you need to enter the correct answer.

The program keeps statistics of your practice, so you can see your weak spots and focus on them, for example by practicing the most difficult entries first.
